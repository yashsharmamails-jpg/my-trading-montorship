# 🧠 AI Context

This folder contains persistent context for AI mentors to maintain continuity across sessions.

---

## 📄 Files

| File | Purpose |
|---|---|
| [full-chat-context.md](./full-chat-context.md) | Complete brain dump — every detail of the mentorship for AI continuity |

---

## 🎯 How To Use

When starting a new chat with an AI:

1. **Share the context file** (paste contents or share repo link)
2. The AI should read [`full-chat-context.md`](./full-chat-context.md) to understand:
   - Who Yash is
   - The system we built
   - Trades analyzed so far
   - Behavioral patterns
   - Current phase & roadmap
   - Mentor's teaching style that works

3. **Update this file** at the end of every session to keep it fresh
