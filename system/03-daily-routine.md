# 🕐 DAILY TRADING ROUTINE

> *Funded traders don't just "open charts and trade." They follow a structured routine that keeps them sharp, disciplined, and emotionally stable.*

---

## ☀️ MORNING ROUTINE (Before Markets — 10:00 AM IST)

**Duration: 30 minutes**

---

### 1. Mindset Reset (5 min)

- [ ] Read your Identity Statement out loud:
  > *"I am a confirmation-based reversal trader. I trade AFTER smart money traps retail traders and structure confirms my direction. I never anticipate. I react."*
- [ ] Remind yourself: *"Today I execute my system. The outcome doesn't matter. My process does."*
- [ ] Accept: Today might be a zero-trade day. That's okay.

---

### 2. Review Your Rules (5 min)

- [ ] Glance at your 7-rule checklist
- [ ] Confirm your limits:

| Limit | Value |
|---|---|
| Max trades today | 2 |
| Max daily loss | 1% |
| If limit hit | I'm DONE for the day |

---

### 3. HTF Analysis (20 min)

- [ ] Open H4/H1 for all 3 pairs
- [ ] For each pair, determine:

| Pair | Structure | Key Zones | Liquidity Pools | Setup Forming? |
|---|---|---|---|---|
| XAUUSD | Bullish / Bearish / Unclear | | | Yes / No |
| NAS100 | Bullish / Bearish / Unclear | | | Yes / No |
| EURUSD | Bullish / Bearish / Unclear | | | Yes / No |

> ⚠️ If no clear bias on a pair → that pair is **OFF LIMITS** today.

## 🇬🇧 LONDON SESSION (12:30 PM – 5:30 PM IST)

---

### Pre-Session (12:30 – 1:00 PM)

- [ ] Check economic calendar — any high-impact news?
- [ ] Review HTF markings — any zones being approached?
- [ ] Set alerts on key levels (don't stare at charts)

---

### Active Trading (1:00 – 4:00 PM)

> This is when London manipulation typically happens.

**Watch for:**
- [ ] Liquidity sweeps of Asian session highs/lows
- [ ] Fakeouts above/below overnight ranges
- [ ] BOS after sweeps

**If setup forms** → Run Pre-Trade Checklist
**If no setup** → Do NOT force one. Step away.

---

### Late London (4:00 – 5:30 PM)

- If you haven't traded → best London setups are likely gone
- Transition to NY preparation
- ❌ Do NOT enter "just because I haven't traded yet"

---

---

## 🇺🇸 NEW YORK SESSION (6:30 PM – 11:30 PM IST)

---

### Pre-Session (6:30 – 7:00 PM)

- [ ] How did London go? Any open positions?
- [ ] Review structure changes from London
- [ ] Update key zones if needed
- [ ] Check for NY news events

---

### Active Trading (7:00 – 10:00 PM)

> NY open often creates manipulation (especially 7:00–8:30 PM IST)

**Watch for:**
- [ ] Sweeps of London session highs/lows
- [ ] Failed breakouts of key levels
- [ ] BOS confirmations after sweeps

**Maximum: 2 trades total for the day (including London)**

---

### Session Close (10:00 – 11:30 PM)

- After 10 PM IST → avoid new entries (liquidity thins out)
- Manage any open trades
- ❌ Do NOT start new positions this late

## 🌙 POST-SESSION ROUTINE (15 minutes)

---

### 1. Journal Your Trades (10 min)

- [ ] Fill out journal template for EVERY trade
- [ ] Include screenshots
- [ ] Grade each trade (A/B/C/D)
- [ ] Be honest about emotions

---

### 2. Daily Debrief (5 min)

| Question | Answer |
|---|---|
| Did I follow my system today? | YES / NO |
| How many trades did I take? | |
| How many were "A" grade? | |
| Did I feel FOMO/revenge/emotional urges? | YES / NO |
| If yes, did I act on them? | YES / NO |
| One thing I did well today | |
| One thing to improve tomorrow | |

---

### 3. Shutdown

- [ ] Close all charts
- [ ] Close TradingView
- [ ] Close trading platform
- [ ] **Done for the day. No peeking at midnight.**
- [ ] Do something non-trading (exercise, family, hobbies)

## 📅 WEEKLY ROUTINE

---

### Sunday Evening (30–45 min)

- [ ] Complete Weekly Review in journal
- [ ] Re-read System Rules document
- [ ] Mark key HTF levels for the week
- [ ] Check economic calendar for the week
- [ ] Identify high-impact news days
- [ ] Set intention: *"This week I will focus on ___"*

---

### Wednesday Mid-Week Check (10 min)

- [ ] How is the week going?
- [ ] Am I following my rules?
- [ ] Am I within my risk limits?
- [ ] If weekly loss limit (2.5%) hit → **no more trading this week**

## 📱 SCREEN TIME RULES

| Rule | Why |
|---|---|
| No charts before morning routine | Don't let price influence your mindset |
| No trading on phone | Phone = impulse = broken rules |
| Set alerts, don't stare | Staring creates FOMO |
| Max 4 hours active chart time/day | More = overtrading brain |
| No charts after shutdown | You need mental recovery |

---

---

## 😤 IF YOU HAVE A LOSING DAY

1. Journal the trades honestly
2. Ask: *"Did I follow my rules?"*
   - **YES:** Normal cost of business. System intact. Move on.
   - **NO:** Write down WHY. What emotion caused it?
3. Do NOT look at charts again today
4. Exercise or walk (burns off cortisol)
5. Come back tomorrow: *"New day, same system."*

---

## 😊 IF YOU HAVE A WINNING DAY

1. Journal the trades
2. ❌ Do NOT "trade more because I'm hot"
3. ❌ Do NOT increase lot size tomorrow
4. Stick to the routine
5. Acknowledge: *"I followed my process. The market rewarded me. Good."*
