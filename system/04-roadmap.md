**How to Backtest:**
1. Go to TradingView → replay mode
2. Start from at least 3 months ago
3. For every candle, ask: "Does this meet ALL 7 rules?"

5. If NO → skip, move forward

| Task | Status |

| Analyze: Which session produces best results? | ⬜ |
| Analyze: Which day of week is best? | ⬜ |
| Analyze: What's my average winner vs average loser? | ⬜ |
| Analyze: Where do my "D" grade trades happen? (time, emotion, pair) | ⬜ |
| Identify losing patterns to REMOVE | ⬜ |
| Identify winning patterns to DOUBLE DOWN on | ⬜ |

---

### Optimization Actions:

| If Data Shows... | Then... |
|---|---|
| Gold has 60% WR but NAS has 35% | Drop NAS or reduce size on it |
| London is 55% WR but NY is 40% | Focus on London, skip NY (or reduce) |
| Tuesday-Thursday is best | Avoid Monday/Friday or trade lighter |
| "D" trades happen after 10 PM | Hard rule: no trades after 10 PM |
| Average winner is 2.5R | Consider letting winners run to 3R |
| Most losses come from chasing | Re-commit to Rule 5 (retest entry) |

---

| Partial profits (close 50% at 1R) | Only if data shows many trades go 1R then reverse |
