## 🔒 Non-Negotiable Rules

1. **No BOS = No Trade**
2. **NO MANUAL EXITS** — Only SL or TP closes a trade
3. **Max 2 trades per day**
4. **Max 1% daily loss / 2.5% weekly loss**
5. **Journal every trade**
6. **If FOMO → do nothing**
7. **If confused → no trade**
8. **1:2 minimum R:R or skip**
9. **Never increase lot size after a loss**
10. **Weekly review every Sunday**
