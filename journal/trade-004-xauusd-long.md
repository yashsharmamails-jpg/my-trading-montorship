## 🎓 Lesson Learned

**If H4 says one direction, M1 cannot override it.**

A bullish M1 BOS inside a bearish H4 trend is just retracement noise. The bigger structure wins. Always.

**Decision tree for the future:**
- H4 + H1 aligned → A-grade setup possible
- H4 + H1 against each other → reduce size or skip
- M1/M5 BOS only → never enough on its own
