# Chart Screenshots

This folder holds all chart screenshots referenced in the journal entries.

## Naming Convention:

```
trade-XXX-<description>.png
```

### Examples:
- `trade-001-entry.png` — Entry setup chart
- `trade-001-htf.png` — Higher timeframe context
- `trade-001-drawdown.png` — Trade in drawdown
- `trade-001-tp-approach.png` — Price approaching TP
- `trade-001-be-hit.png` — Stopped at breakeven
- `trade-002-entry.png` — Trade 2 entry
- `trade-002-post-exit.png` — Price after manual exit

## How To Add Images:

1. Save the chart screenshot from TradingView
2. Rename it following the convention above
3. Drop it in this folder
4. The journal `.md` files will automatically reference them
